# ساخت APK Ario

این پوشه Ario را با Capacitor به یک برنامهٔ اندروید تبدیل می‌کند. خود برنامه در `www/index.html` است.

## راه اول: ساخت خودکار روی GitHub (بدون نصب چیزی روی کامپیوتر)

۱. در github.com یک حساب رایگان بساز.

۲. روی **New repository** بزن، نام `barnameyar` را بنویس و **Create repository** را بزن.

۳. فایل‌ها را بارگذاری کن:
   - در صفحهٔ مخزن، **uploading an existing file** را بزن و همهٔ محتویات همین پوشه را بکش و رها کن.
   - پوشهٔ `.github` مخفی است. در مک با `Cmd + Shift + .` و در ویندوز با «Hidden items» آن را نشان بده.
   - اگر `.github` بارگذاری نشد، از ترمینال استفاده کن:
     ```
     git init
     git add .
     git commit -m "first"
     git branch -M main
     git remote add origin آدرس-مخزن-تو
     git push -u origin main
     ```

۴. به تب **Actions** برو، روی **Build Android APK** بزن و **Run workflow** را بزن. حدود ۵ دقیقه طول می‌کشد. با هر بار بارگذاری تازه هم خودکار اجرا می‌شود.

۵. وقتی اجرا سبز شد، رویش بزن. پایین صفحه در بخش **Artifacts** فایل `barnameyar-apk` را دانلود کن. داخل این zip فایل `app-debug.apk` است.

۶. `app-debug.apk` را به گوشی بفرست و باز کن. اگر اندروید پرسید، اجازهٔ «نصب از منابع ناشناس» را بده.

این APK برای استفادهٔ شخصی و آزمایش خوب است. برای انتشار در فروشگاه‌ها به نسخهٔ امضاشده نیاز داری (پایین‌تر توضیح داده شده).

## راه دوم: ساخت روی کامپیوتر خودت

نیاز داری: Node.js نسخهٔ ۲۰ یا بالاتر، Java 17 و Android Studio.

```
npm install
npm run build:web
npx cap add android
bash scripts/apply-icons.sh
bash scripts/android-setup.sh
npx cap sync android
npx cap open android
```

در Android Studio از منوی **Build > Build APK(s)** استفاده کن. در ویندوز دستور `bash` را در Git Bash اجرا کن، یا پوشه‌های `icons/mipmap-*` را دستی داخل `android/app/src/main/res` کپی کن.

## زبان‌ها (فارسی و انگلیسی)

- زبان از **حساب > تنظیمات ظاهری > زبان · Language** عوض می‌شود (در صفحه‌ی خوش‌آمدی هم دکمه دارد). برنامه بعد از تغییر دوباره بارگذاری می‌شود.
- نصب تازه: اگر زبان گوشی فارسی باشد برنامه فارسی است، در غیر این صورت انگلیسی. کاربران فعلی فارسی می‌مانند.
- انگلیسی: چیدمان چپ‌به‌راست، تقویم میلادی، شروع هفته از یکشنبه، ارقام لاتین، بدون تعطیلات ایران، و افزودن سریع کار با جمله‌ی انگلیسی (مثلاً `tomorrow at 5pm meeting #work !important`). بخش «کنکوریا» فقط فارسی است و در انگلیسی پنهان می‌شود.
- متن‌ها: در کد با `__("متن فارسی")` علامت خورده‌اند و ترجمه‌ی انگلیسی‌شان در `src/js/i18n-en.js` است (کلید = متن فارسی). برای متن تازه، آن را با `__()` بپیچ و ترجمه‌اش را به این فایل اضافه کن. `build-web.sh` سه فایل `i18n-en.js`، `i18n.js` و `app.js` را به هم می‌چسباند.
- سمت اندروید: `ArioLang.java` زبان را نگه می‌دارد (دکمه‌های اعلان، کانال‌ها، ویجت).

## تغییر دادن برنامه

کد خوانا در `src/js/app.js` و `src/css/app.css` است. فایل‌های داخل `www/js` و `www/css` نسخهٔ فشرده‌ی همین‌ها هستند و خودکار ساخته می‌شوند، پس مستقیم عوض‌شان نکن.

۱. فایل‌های `src` (یا `www/index.html`) را عوض کن.
۲. `npm run build:web` را بزن تا نسخهٔ فشرده ساخته شود (در ساخت خودکار GitHub این مرحله خودش اجرا می‌شود).
۳. دوباره بارگذاری کن (راه اول) یا `npx cap sync android` را بزن (راه دوم).

## نسخهٔ امضاشده برای انتشار

- در Android Studio: **Build > Generate Signed Bundle / APK**. فایل کلید امضا را نگه دار و گمش نکن.
- بازار و مایکت فایل APK می‌گیرند. گوگل‌پلی فایل AAB می‌خواهد و یک بار ۲۵ دلار ثبت‌نام دارد.
- اگر قصد انتشار داری، شناسهٔ بسته (`appId` در `capacitor.config.json`) را قبل از اولین انتشار به چیز یکتای خودت تغییر بده. بعد از انتشار قابل تغییر نیست.

## v218 (ثبت آزمون و پرسش از آمار با صدا)

- **ثبت آزمون با صدا:** به آریو بگو «آزمون ۱۲ مهر: ریاضی ۴۵ درصد، فیزیک ۳۰ درصد» (یا با عدد و کلمه، «دوازدهم مهر»، «چهل و پنج درصد»، «منفی ۱۰ درصد»، «۶۲٫۵ درصد»). آزمون با همان تاریخ (آخرین ۱۲ مهر) در «کنکوریا ← تخمین رتبه ← تاریخچه» ذخیره می‌شود و رتبه‌ی کشوری و درصد وزنی را می‌گوید. اگر دوباره همان آزمون را با همان نام و تاریخ بگویی، به‌روز می‌شود (تکراری نمی‌سازد). گروه آزمایشی، سال، منطقه و سهمیه از همان «تخمین رتبه» برداشته می‌شود؛ درسی که در آن گروه نیست رد می‌شود و آریو می‌گوید.
- **دکمه‌ی میکروفون در صفحه‌ی تخمین رتبه** (بالا، کنار تنظیمات) همین کار را بدون باز کردن آریو انجام می‌دهد.
- **سؤال از آمار** (آفلاین، از داده‌ی خود برنامه):
  - «این هفته چند ساعت خوندم؟» ← جمع ساعت‌های مطالعه از اول هفته (شنبه) تا امروز، روزهای فعال، پرمطالعه‌ترین درس، و جمع ۷ روز اخیر.
  - «ضعیف‌ترین درسم کدومه؟» ← کم‌ترین میانگین درصد در ۳ آزمون آخرِ «تخمین رتبه»، درس بعدی، و مطالعه‌ی ۳۰ روز اخیر برای همان درس. اگر آزمونی ثبت نشده باشد، از روی کم‌خوانده‌ترین درس می‌گوید.
  - «رتبه‌ام الان حدوداً چنده؟» ← همان برآوردِ صفحه‌ی تخمین رتبه (آخرین آزمون + تا ۲ آزمون قبلی): رتبه‌ی کشوری، بازه، رتبه در سهمیه و میزان اطمینان.
- کد: `aoExamSave`، `aoExamPairs`، `aoStatWeek`، `aoStatWeak`، `aoStatRank` و `actions.rkVoice` در `src/js/app.js` (بخش «voice exam entry + questions about the stats»)، قصدها در `aoIntent` (`exam`، `statWeek`، `statWeak`، `statRank`).
- کارت «تخمین رتبه» در صفحه‌ی کنکوریا حالا آزمونی را نشان می‌دهد که **تاریخ آن** تازه‌تر است (نه آخرین آزمونِ واردشده).
- تست‌نشده روی گوشی واقعی: تشخیص گفتار فارسی گوگل گاهی عددها را به‌صورت حروف یا با «٪» می‌نویسد؛ هر دو حالت در منطق پوشش داده شده، ولی دقیقاً همان‌طور که در گوشی تشخیص داده می‌شود امتحان نشده.

## مرور فاصله‌دار، پرسش و پاسخ شفاهی و یادآور هدف (دستیار آریو)

- «امروز چی رو مرور کنم؟»: از روی لاگ مطالعه (کنکوریا)، درس‌هایی که چند روز سراغشان نرفته‌ای پیشنهاد می‌شود (فاصله‌ها: ۳، ۵ و ۷ روز؛ پاسخ ضعیف در پرسش، فاصله را کوتاه‌تر می‌کند). می‌شود از همان‌جا کار مرور ساخت.
- «ازم بپرس»: سه سؤال شفاهی از مباحثی که ثبت کرده‌ای؛ جواب را بگو یا بنویس، بعد خودت امتیاز بده (کامل / نیمه‌بلد / یادم نبود). امتیاز در `profile.sr` ذخیره می‌شود و روی پیشنهاد مرور اثر می‌گذارد.
- «اگه تا ساعت ۹ شب هدفم کامل نشد یادم بنداز»: `profile.gr` ذخیره می‌شود. اعلان محلی فقط تا وقتی هدف کامل نشده برنامه‌ریزی می‌شود (با هر تغییر دوباره محاسبه می‌شود) و اگر برنامه باز باشد در خود برنامه هم نشان داده می‌شود. «هدف» پیش‌فرض هدف مطالعه‌ی روزانه است؛ اگر بگویی «کارها»، هدف تعداد کارهای روزانه بررسی می‌شود. «یادآور هدف را لغو کن» آن را پاک می‌کند.

## روند حال و جمع‌بندی شب (دستیار آریو)

- اگر چند روز پشت‌سرهم (۳ روز، با امروز) به آریو بگویی خسته‌ای، استرس داری، کار زیاد داری یا بی‌انگیزه‌ای، آریو یک بار با ملایمت پیشنهاد می‌دهد برنامه را سبک کنی؛ حداکثر هر ۵ روز یک بار. روزها در `profile.md` و روز آخرین پیشنهاد در `profile.mo` ذخیره می‌شود.
- «امروز چطور بود؟» یا «جمع‌بندی شب»: کارها، تمرکز و مطالعه‌ی امروز با یک جمله‌ی تشویقی؛ کارهای مانده را می‌شود با یک دکمه به فردا برد.

## جواب‌های غیرتکراری آریو

برای هر حالت (خسته، استرس، انگیزشی…) همه‌ی جواب‌ها یک دور کامل استفاده می‌شوند و بعد دور تازه شروع می‌شود؛ جوابی که دور قبل تمام شد، اول دور بعد نمی‌آید. آخرین جواب هر حالت در `localStorage` (کلید `ario.last`) می‌ماند تا با بستن و باز کردن برنامه هم تکرار نشود.

## تحلیل‌گر عربی برای ثبت سریع کار

وقتی زبان برنامه عربی است، ثبت سریع کار (و ثبت کار از طریق آریو) از `nlParseAr` استفاده می‌کند و دیگر قواعد فارسی را دنبال نمی‌کند. مثال‌ها:
`غداً الساعة ٥ مساءً اجتماع مع أحمد !عاجل` · `بعد غد الساعة 9 صباحاً مراجعة` · `يوم الاثنين الساعة ٣ ونصف عصراً` · `15 نوفمبر امتحان` · `20/12 تسليم` · `الخميس القادم الساعة ٨ إلا ربع مساءً` · `اليوم من الساعة ٤ إلى ٦ مساءً` · `بعد ٣ أيام` · `كل أسبوع` · `#وسم`.
تاریخ‌ها میلادی‌اند (روز + نام ماه، یا روز/ماه). عنوان کار با املای اصلی (همزه و تای مربوطه) حفظ می‌شود.

## ابزارهای متن PDF (v228)
- **جستجو در متن کتاب**: بیشتر ← جستجو در متن کتاب. صفحه‌ها یک بار با همان موتور OCR آفلاین خوانده و در حافظه ذخیره می‌شوند.
- **هایلایت روی متن**: در حالت خواندن روی یک کلمه نگه دار، بکش یا دستگیره‌ها را جابه‌جا کن و رنگ را بزن. فهرست: بیشتر ← هایلایت‌های کتاب.
- **حالت شب و نور صفحه**: دکمهٔ ماه پایین صفحه، یا بیشتر ← حالت شب و نور صفحه.
- **جدا کردن صفحه‌ها**: بیشتر ← جدا کردن صفحه‌ها. به `pdf-lib` نیاز دارد (در `npm install` و `build:web` اضافه شده).

## حساب واقعی با Supabase (v230)
۱. در supabase.com یک پروژهٔ رایگان بساز. در **SQL Editor** محتویات `supabase/setup.sql` را اجرا کن.
۲. **Authentication ← Providers ← Email**: برای شروع «Confirm email» را خاموش کن (در غیر این صورت لینک تأیید در موبایل درست باز نمی‌شود).
۳. **Project Settings ← API**: `Project URL` و کلید `anon public` را در `src/js/app.js` در خط `var SB={url:'',key:''};` بگذار. کلید `service_role` را هرگز در برنامه نگذار.
۴. بساز و نصب کن. در «حساب کاربری ← ورود یا ساخت حساب» با ایمیل و رمز وارد شو. کارهای همین گوشی بعد از اولین ورود با کارهای حساب ادغام می‌شوند.
تا وقتی `url` و `key` خالی‌اند، برنامه مثل قبل فقط روی خود گوشی کار می‌کند.
