# Ario (barnameyar-android) — notes for whoever edits this project

## Ario Channel (کانال Ario) — one post per change
The app has a read-only channel (Today screen → first banner → `#/channel`). Its posts live in `src/js/channel-posts.js`.

**Every time you change something the user can see or add a feature, add a channel post in the same change:**

```
node scripts/add-channel-post.mjs --title "عنوان کوتاه" --text "یکی دو جمله برای کاربر" \
  --kind new   --img path/to/picture.webp --en-title "..." --en-text "..."
```
- `--kind`: `new` (new feature), `imp` (improvement), `fix` (bug fix), `info` (news).
- Write for the user, not for developers; add a picture when the change is visual (screenshot or an image from `www/img`).
- Then `npm run build:web`. Posts are bundled in the app, so they appear with the update; people see a number on the channel banner and a notice.

## Build
Readable sources: `src/js`, `src/css`. `www/js` and `www/css` are generated by `npm run build:web` (do not edit them).
New user-facing text: wrap in `__("فارسی","English")`.
